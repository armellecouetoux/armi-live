      Sincronizar entre dispositivos

      Los cambios se guardan en el archivo state.json de tu repositorio armi-live. Para poder escribir en él, cada dispositivo necesita un token de GitHub (solo hace falta pegarlo una vez por navegador).

      1. Abre este enlace a GitHub: el token ya viene con nombre, duración de un año y permiso de escritura en Contents.
      2. En Repository access elige Only select repositories → armi-live.
      3. Comprueba que Contents esté en Read and write, pulsa Generate token y cópialo aquí abajo.
