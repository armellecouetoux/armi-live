      Sincronizar entre dispositivos

      Los cambios se guardan en el archivo state.json de tu repositorio master-to-do. Para poder escribir en él, cada dispositivo necesita un token de GitHub (solo hace falta pegarlo una vez por navegador).

      1. Abre GitHub → nuevo token (fine-grained).
      2. En Repository access elige Only select repositories → master-to-do.
      3. En Permissions → Contents elige Read and write. Genera el token y cópialo.
